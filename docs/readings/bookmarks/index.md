# Bookmarks

Curated external technical blogs and articles worth reading through. Links open
in a new tab.

- [gpfault.net](https://gpfault.net/){ target=_blank rel=noopener .external-link } — technical blog on computer graphics and low-level programming.
- [xorpd](https://www.xorpd.net/){ target=_blank rel=noopener .external-link } — assembly programming articles, puzzles, and challenges.
- [Agner Fog — software optimization resources](https://www.agner.org/optimize/){ target=_blank rel=noopener .external-link } — optimization manuals, x86 instruction tables, and microarchitecture guides.
- [x86 Assembly Guide (UVa CS216)](https://www.cs.virginia.edu/~evans/cs216/guides/x86.html){ target=_blank rel=noopener .external-link } — concise introduction to x86 assembly.
- [x86 and amd64 instruction reference](https://www.felixcloutier.com/x86/){ target=_blank rel=noopener .external-link } — searchable x86/x86-64 instruction set reference drawn from the Intel manuals.
